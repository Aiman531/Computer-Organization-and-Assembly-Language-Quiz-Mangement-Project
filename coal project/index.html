About Project
Project Overview

This project is a Quiz Engine developed as part of the Computer Organization and Assembly Language course. The quiz engine is entirely written in 8086 Assembly Language using TASM (Turbo Assembler).

Features
  • Multiple choice quiz system
  • Real-time score calculation
  • Record generation (RECORD.TXT)
  • Category-based questions
  • User authentication
Technology Stack
  • Assembly Language: 8086 Architecture
  • Assembler: TASM (Turbo Assembler)
  • Frontend: HTML, CSS, JavaScript, Bootstrap 5
  • Visualization: Chart.js
How to Use
  1. Run the Assembly quiz engine (.EXE file)
  2. Complete the quiz
  3. The program generates RECORD.TXT
  4. Upload RECORD.TXT to the Records page
  5. View analytics on the Dashboard
