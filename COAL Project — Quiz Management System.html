Problem Statement

🧩

Isolation of Assembly Learning

Students study 8086 Assembly Language in isolation without seeing how it connects to real-world applications and modern tech stacks.

📊

No Performance Analytics

Educators lack tools to visualize quiz performance across categories. Existing systems don't expose underlying data mechanisms.

💾

File I/O Without Libraries

Demonstrating persistent data storage using raw DOS INT 21h interrupts—without any C runtime or external library—remains unexplored.

🔗

Interoperability Gap

A clear gap exists between classical system-level programming and contemporary web development paradigms in academic projects.

Assembly Module & File Handling

; ── Score Computation ──────────
MOV  BL, 0          ; init score

INT  21h           ; AH=09h display Q
INT  21h           ; AH=01h read ans
CMP  AL, correct   ; check answer
JNE  next_q        ; wrong → skip
INC  BL            ; correct → +1

; ── File Write (Append) ────────
MOV  AH, 3Ch       ; Create file
LEA  DX, filename
INT  21h
MOV  BX, AX        ; file handle
MOV  AH, 40h       ; Write data
LEA  DX, record
INT  21h
MOV  AH, 3Eh       ; Close file
INT  21h

INT 21h File Operations

AH=3Ch
Create File
Creates RECORD.TXT; CX=0 normal attr
AH=3Dh
Open File
Opens read-write; AL=02h
AH=42h
Seek End
Moves pointer for append; AL=02h
AH=40h
Write File
Writes CX bytes from DS:DX buffer
AH=3Eh
Close File
Closes handle BX, flushes writes
